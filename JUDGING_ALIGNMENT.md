# Nexathon Judging Alignment

This map is based on the Nexathon 2026 brochure supplied with the project. It is a preparation aid, not a claim that judges have approved the implementation.

| Published judging criterion | Evidence to demonstrate | Honest current position / next improvement |
|---|---|---|
| Innovation & Creativity | Explainable, local-first practice flow linking scenarios to targeted learning activities. | The implementation is a focused adaptation/prototype, not a claim of unprecedented invention. Explain what is distinctive in the design and acknowledge the inherited code foundation. |
| Technical Complexity | Next.js/TypeScript application, authentication, API validation, Prisma persistence, scenario-aware local Ollama evaluator, structured rubric validation, and progress logic. | Show the architecture and tests. Production build, live Ollama, database and browser workflow testing remain required pre-demo verification steps. |
| Functionality & Usability | Create an assessment, answer scenarios, view feedback, review history and compare eligible results. | Only claim features demonstrated live. Run the acceptance plan on the actual machine before judging. |
| Presentation & Communication | Five-minute flow in `DEMO_SCRIPT.md`; clear problem, workflow, architecture and limitations. | Keep the demo focused; avoid overclaiming AI capabilities or validated behaviour measurement. |
| Impact & Scalability | Practice activities may support learning and development; local API-free scoring lowers integration cost. | Real organisational use requires validated assessment methods, accessibility and bias reviews, privacy controls, and human oversight. |

## Fit to the supplied problem statement
The brochure's “AI-Based Employee Behaviour & Workplace Assessment” statement calls for structured workplace scenarios and employee responses to help identify strengths, development areas, and suitable training interventions. Workplace Compass implements a prototype of that workflow through curated scenarios, written responses, rubric feedback and competency-linked practice actions.

## Suggested judge-facing one-liner
"Workplace Compass is an explainable workplace-practice platform that turns realistic scenarios into structured feedback and targeted learning actions, using local Ollama inference without requiring a hosted AI API."
