## Submission integrity and responsible-use notes

- The project is an adaptation of the TakeInt source archive supplied for this project. The inspected archive did not include a root licence file; verify upstream licensing and asset terms before public redistribution. Do not claim all inherited code is original.
- The score is generated by a local Ollama model against a scenario-specific rubric. AI feedback can be wrong and is not a validated psychological or employee-performance measurement. Do not use it as the sole basis for HR/employment decisions.
- Only claim a workflow is functional in a live judging demo after it has been demonstrated on the actual machine.
